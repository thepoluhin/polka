# Звук листания

- `bookFlip1.ogg` — исходная запись из набора «RPG Audio» от Kenney (www.kenney.nl), лицензия CC0 (см. `License-Kenney-RPG-Audio.txt`).
- `page.ogg` — звук в программе: та же запись без удара листа в конце (шелест 0,04–0,57 с, плавное затухание),
  срезаны частоты выше ~2,6 кГц и ниже ~110 Гц, чтобы шелест был мягким.
